# SilicaMentis

SilicaMentis Strategy – website and brand files.

## Layout
- `website/` – the silicamentis.eu site (static HTML). See `website/README.md` for how changes go live. When Netlify is linked to this repo, its base directory is `website`.
- `brand/` – brand files that are not part of the site (Instagram profile images, Teams backgrounds). Master logos live in `website/assets/`.

Other SilicaMentis projects (TIDAL, Vadum, BioLures) are separate repos in the SilicaMentis-Strategy organisation, kept beside this folder, never inside it.
